THE PRIVACY BOUNDARY

Your inbox stays between Google and your browser.

No Inbox Island server

Mail is fetched directly from Google into the extension and classified locally.

Read only

Google's restricted gmail.readonly scope can read mailbox content, but cannot send, edit, label, archive, delete, or mark mail read.

Explicit every time

In Google Chrome, you approve access, confirm the returned Gmail address, and start each bounded sync yourself.

Short-lived access

Inbox Island holds the token only in memory and asks Chrome to clear its extension token cache after each run and on Disconnect.

Minimal local state

Only account-scoped triage results are stored locally—not raw bodies, HTML, attachments, summaries, or OAuth credentials.

Built for auditability

Public source, build instructions, Store disclosures, an SBOM, and package receipts are available now.
