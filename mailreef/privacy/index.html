Mailreef

Privacy Policy

Effective November 2, 2026. Mailreef is a private Gmail screening assistant operated by Jared Pearson (“JPop”) with his personal AI assistant, Sean. This policy covers Mailreef’s use of Google account data, not other services on jpop.cloud.

Google data accessed

With an account owner’s OAuth consent, Mailreef may access the selected Gmail account’s identity, message and thread identifiers, sender and recipient information, subject, timestamps, labels, snippets, and message text needed for an operator-requested read. Mailreef requests only gmail.readonly plus basic identity scopes. It does not request Gmail permissions to send or modify mail, and it does not read attachments.

How Google data is used

Google user data is used only to discover messages requested by an authorized operator, screen them as untrusted content, and return a bounded summary. Mailreef does not use Google user data for advertising, credit decisions, unrelated profiling, or training or improving a generalized or foundation AI model.

Processing and sharing

OAuth credentials remain on the operator’s private device. Selected email data is handled by a local broker and may be sent to the configured AI model provider solely for isolated screening and summarization under that provider’s API terms and the operator’s project settings. Mailreef does not sell Google user data or share it with advertisers or data brokers.

Storage and retention

OAuth credentials are stored in private, account-isolated files on the operator’s device. Mailreef does not store raw message bodies in its public source repository or public website. Local security audit records and private assistant task records may retain message identifiers, screened summaries, safety receipts, and task results as needed for operation and troubleshooting. They can be deleted on request, subject to any legal obligations.

Controls and deletion

An account owner can revoke Mailreef at any time from Google Account connections. To request deletion of locally retained Mailreef data or ask a privacy question, email pearson.jaredb@gmail.com. Do not include mailbox content, credentials, OAuth codes, or private screenshots in public support requests.

Security

Mailreef uses read-only Google permission, private credential isolation, bounded discovery, a local broker, deterministic content checks, isolated screening stages, and fail-closed release gates. Email content never authorizes navigation, purchases, account changes, messages, or other external actions. No security control eliminates all risk.

Google API Limited Use

Mailreef’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Material changes will be reflected by updating the effective date on this page.
